# Grandfather crown workshop

The authored starter now uses an 800 m tree with a 280 m trunk, respectively twice the previous height and twenty times its width. The doorway and home branch remain at 75% height, now 600 m. The trunk is shifted left so its visible doorway stays beside the same local launch origin. The world extends to 3,000 m altitude; the five zones and low-gravity transition double their old altitude ranges. Gravity remains 8.825985 m/s², with 14% of that baseline in space. These are user-directed game dimensions, not new world canon.

The starter has 267 editable objects: 79 fixed-size enemies, 97 leaf fields, solid boughs, slopes, stepping platforms and seven sap patches. There are no solid leaf surfaces in the new starter; older green branch material remains available as Mossy wood for compatibility. Decorative bough sections pass behind the launch shaft to leave room for large builds; their outer routes remain solid. Clear launch geometry is authored map data, not a collision exception in the engine.

The backdrop builds one complete world-space trunk and crown, plus distant forest trees, roots, fern fans, fungi and hanging vines. Close views add layered vector leaf sprays. Parallax fades at overview scale so the whole physical silhouette stays proportional. Both editor and game have whole-tree framing; the game also has zoom buttons and wheel zoom, with automatic animal follow restored by Fit. Rendering culls objects, simplifies unresolved enemy silhouettes and caps leaf detail.

Leaves and sap are non-solid interaction volumes made from circles or simple concave polygons. One 0.2 m leaf at density 1 retains 99.64% of incoming speed. Leaf attenuation compounds as exp(-0.018 × density × path length). Dense fields and overlapping fields accumulate; gravity continues every physics step, so leaves never act as an invisible floor. Sap retains exactly 1% of velocity on entry and does not repeatedly multiply speed while the critter remains inside. Future foliageResistance/sapResistance fields are supported; existing critters default to zero resistance.

A static spatial hash indexes volumes. Swept paths catch thin spots between timesteps. Round expansion and bounded capsule samples account for the actual critter's width, length and orientation; concave notches stay open. This is an arcade vegetation-drag model, not per-leaf deformable physics. It removes kinetic energy and never supplies launch energy. Soft rustle and sticky cues are separate from bumper/ground sounds.

Branch draws a tapered sloping segment. Select a wooden polygon and Extend branch, then tap the new tip, to add an attached segment. Slope draws a platform with an inclined top edge. Single leaf and Dense cluster presets set the leaf brush density, which is also editable in the inspector. Solids, leaves and sap can be picked separately. Eraser removes a whole piece and Undo restores it. Copy piece duplicates; Copy map provides a portable link or complete JSON for a later authored default.

Old edited v2 maps stay intact. Untouched prior starter maps upgrade to the new starter automatically. Load new starter under Maps & backups explicitly replaces a custom layout with this starter, with session Undo available. Shared v2 snapshots retain their own old geometry and altitude model; v3 snapshots carry the full crown and interaction fields. Personal edits stay browser-local until exported or shared.

## Verification

388 automated tests pass, including swept thin/concave fields, per-entry sap, resistance, timestep-independent leaf drag, large-body interaction, 1,800-object query locality, branch tapering, migration and overview camera proportions. Local browser checks exercised branch drawing, extension, duplicate/erase/Undo, slope drawing, leaf density, sap, new-starter restore and Creative playtests. Copy map JSON reported success; decoding the portable link independently confirmed all 267 objects and tree dimensions. Shared opening kept the saved map safe. The starter mouse released at 38 degrees and 24.1 m/s. No browser errors appeared during that launch. Portrait editor/game controls were reviewed at 390×844 and 320×667; this is viewport QA, not measured phone hardware performance. Screenshots are retained in this folder.
